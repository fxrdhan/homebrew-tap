# fxrdhan Homebrew Tap

Official Homebrew formulae for projects by [fxrdhan](https://github.com/fxrdhan).

## Installation

To install `lez`:

```bash
brew install fxrdhan/tap/lez
```

Or tap first:

```bash
brew tap fxrdhan/tap
brew install lez
```

### Install Latest Main Branch (HEAD)

```bash
brew install --HEAD fxrdhan/tap/lez
```

## Available Formulae

| Formula | Description |
|---|---|
| [`lez`](Formula/lez.rb) | A modern, fast, and feature-rich replacement for `ls` written in Rust |
